🌙 Seed Data Manajemen Keuangan Ramadhan

⚠️ Perhatian:
Tool ini akan mengisi data contoh otomatis ke aplikasi Anda. Data lama akan ditimpa jika sudah ada.

Pilih Dataset:

Dataset Dasar Berisi:

  • 3 Anggota (Ibu Umum, Bapak Sholeh, Adik Fauziah)
  • Saldo Rp 100.000 - 150.000 per anggota
  • Hari Ramadhan: Hari ke-1

Dataset Lengkap Berisi:

  • 5 Anggota dengan saldo berbeda
  • 5 Jadwal masak
  • 20+ Riwayat transaksi simulasi
  • Hari Ramadhan: Hari ke-5
